## smt-ci-api-frontend

这是 [smt-ci-api-rs](https://github.com/sTheNight/smt-ci-api-rs) 的配套前端。

由 React + shadcn/ui + Tailwind CSS 构建。

## Usage

需要 Node.js 环境，并执行：

```bash
pnpm install
pnpm build
```

构建完成后，将产物放置到后端可执行文件目录下的 /dist 目录中

此外还需要把 `.env.example` 重命名为 `.env` 然后根据实际情况填入 API 地址
